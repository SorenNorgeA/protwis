How to use — GPCRome wheel

Each row has a receptor cell and a second cell for a numeric value (Numeric mode) or a text label (Text mode). Type at least one character in the receptor cell to open suggestions (formatted GtoPdb-style receptor names with genes); chosen receptors show as formatted names while the plot uses the canonical UniProt entry behind the scenes. Paste multi-line/tab data in the table as before.

Use Numeric for heatmap colouring by number, or Text for text categories shared across receptors (Colours menu lists unique labels once; two identical labels use the same colour). An extra swatch appears beside the label cell in Text mode. Use Legend layout (toolbar) to arrange the categorical legend in Text mode.

Use Select from table for a searchable GPCR list (same set as this wheel): filter columns, tick rows, then Add to table to fill receptors in the grid.

Paste from Excel: One column while focused in the value/label or Receptor column fills that column only from the current row downward (overwrites existing rows; adds rows if needed). Two tab-separated columns update both columns from the focused row the same way; paste with focus outside the grid still appends new rows.

Unknown receptors are outlined in red; invalid numbers red on the value cell in Numeric mode. A valid receptor with an empty second cell shows an orange hint (hover): enter a number or a label depending on mode. Duplicate receptors: last row wins. Max 500 rows; validation runs locally in your browser.

An empty row is kept at the bottom of the table for quick entry.
